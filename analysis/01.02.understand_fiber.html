🧬 01.02 - Understanding Fiber Node Structure

🎯 Concept: What a Fiber node contains and how fibers relate to each other

⏱️ Time: 15 minutes | 🎓 Difficulty: Beginner

🧠 Core Concept

A Fiber node is React's internal representation of a component or element. While VDOM objects describe what you want to render, Fiber nodes track how to render it, including work state, relationships, and effects.

Key Point: Every React element becomes a Fiber node. Fibers form a tree structure that mirrors your component hierarchy.

📊 Fiber Node Properties

🏷️ Identity & Type

tag: Fiber type (0=FunctionComponent, 1=ClassComponent, 5=HostComponent)
type: Component function or HTML tag string
key: Unique identifier for reconciliation
elementType: Original element type

🔗 Tree Relationships

return: Parent fiber
child: First child fiber
sibling: Next sibling fiber
index: Position among siblings

💾 State & Props

pendingProps: New props to be applied
memoizedProps: Props from last render
memoizedState: Component state or hooks
stateNode: DOM node or component instance

⚡ Work & Effects

flags: Side effects to perform
lanes: Priority of this fiber's work
alternate: Work-in-progress counterpart
updateQueue: Pending updates

🌳 Fiber Tree Structure

App (FunctionComponent) ├── div (HostComponent) │ ├── h1 (HostComponent) │ │ └── "Hello World" (HostText) │ └── Counter (FunctionComponent) │ └── button (HostComponent) │ └── "Count: 0" (HostText)

Navigation: Each fiber knows its parent (return), first child (child), and next sibling (sibling)
