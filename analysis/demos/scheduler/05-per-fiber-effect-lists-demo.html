Key Concepts:

  1. Per-Fiber Effect Lists - Each fiber has its own `updateQueue.lastEffect`
  2. Independent Collection - Effects are collected per fiber during render
  3. Separate Execution - Each fiber's effects are executed independently
  4. Component Isolation - Effects don't interfere between components
  5. Tree Traversal - Effects are processed in component tree order

How Per-Fiber Effect Lists Work:

  • Fiber Creation - Each fiber starts with `updateQueue = null`
  • Effect Collection - Effects added to current fiber's list only
  • Circular Lists - Each fiber maintains its own circular linked list
  • Independent Execution - Each fiber's effects executed separately
  • Cleanup Isolation - Each fiber cleans up its own effects
