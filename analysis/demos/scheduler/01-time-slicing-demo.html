Key Concepts:

  1. Time Slicing - React breaks work into small chunks that can be interrupted
  2. shouldYieldToHost() - Determines when to yield control back to browser
  3. Work Loop - Processes one fiber at a time, checking yield conditions
  4. Resume Capability - Can restart from where it left off
  5. Priority Levels - Different priorities have different time slices

How It Works:

  • Start - Scheduler begins processing fibers
  • Check Yield - After each fiber, check if should yield
  • Yield - If time slice expired, pause and return control
  • Resume - Later, continue from the same fiber
  • Complete - When all fibers done, commit changes
