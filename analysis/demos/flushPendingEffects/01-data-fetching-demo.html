flushPendingEffects Demo: Data Fetching

User Profile Component

This demo shows how flushPendingEffects affects data fetching with useEffect.

Timeline will appear here...

What's Happening:

  1. Component Renders - React renders the component with initial state
  2. DOM Updates - Browser updates the DOM to show loading state
  3. flushPendingEffects Runs - React executes useEffect hooks
  4. Data Fetching Starts - useEffect triggers the API call
  5. State Updates - When data arrives, component re-renders

Key Points:

  • User sees loading state immediately after clicking
  • Data fetching happens after DOM updates
  • Effects run in the correct order and timing
  • Cleanup functions prevent memory leaks
