What's Happening:

  1. Modal Component Renders - React renders the modal component
  2. DOM Updates - Browser adds modal to DOM
  3. flushPendingEffects Runs - React executes useEffect
  4. DOM Manipulation - useEffect sets overflow: hidden
  5. User Experience - Background scroll is disabled

Key Points:

  • DOM manipulation happens after the modal is visible
  • Effects can modify the DOM safely after React's updates
  • Cleanup functions restore the original state
  • User sees immediate visual feedback, then behavior changes
