What's Happening:

  1. Component Renders - React renders the chat room component
  2. DOM Updates - Browser updates the DOM with empty message list
  3. flushPendingEffects Runs - React executes useEffect
  4. Subscription Established - useEffect creates subscription to chat room
  5. Real-time Updates - Messages flow in through subscription
  6. Cleanup on Unmount - Subscription is removed when leaving room

Key Points:

  • Subscriptions are established after component is mounted
  • Cleanup functions prevent memory leaks
  • Real-time data flows continuously
  • Switching rooms properly cleans up old subscriptions
