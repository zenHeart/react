📖 01.01 - Understanding Virtual DOM Objects

🎯 Concept: What React.createElement() returns

⏱️ Time: 15 minutes | 🎓 Difficulty: Beginner

🧠 Core Concept

When you write JSX like <button>Click me</button>, Babel transforms it to React.createElement("button", null, "Click me"). This function returns a Virtual DOM object - a plain JavaScript object that describes what you want to render.

Key Point: VDOM objects are NOT DOM elements. They're descriptions of DOM elements.

🔬 Interactive Exploration

Create and Inspect VDOM Objects

📊 VDOM Object Structure

type: String (HTML tag) or Function (component)
key: Unique identifier for reconciliation
props: Object containing attributes and children
props.children: Array of child elements
_owner: Component that created this element
_store: Internal React metadata

Example VDOM Object:

{ type: "button", key: null, props: { className: "btn", onClick: function() { ... }, children: "Click me" }, _owner: null, _store: { validated: false } }
