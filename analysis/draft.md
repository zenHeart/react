

| 类别             | 字段名             | 类型                                        | 功能描述                                                                                                                                                                             |
| :--------------- | :----------------- | :------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **基本标识信息** | `tag`              | `WorkTag`                                   | 标识 Fiber 的类型，例如是函数组件、类组件、宿主组件（如 `div`）、文本节点等。                                                                                                    |
|                  | `key`              | `null \| string`                            | 唯一标识此子节点，用于在调和过程中优化列表渲染和元素移动。                                                                                                                       |
|                  | `elementType`      | `any`                                       | 元素的原始类型，例如 `<div />` 中的 `div`，或 `<MyComponent />` 中的 `MyComponent`。用于在协调过程中保留元素的身份。                                                             |
|                  | `type`             | `any`                                       | 经解析后的函数或类，对应于 `elementType`。例如，如果是函数组件，`type` 就是该函数；如果是宿主组件，`type` 就是 DOM 元素的标签名。                                                 |
|                  | `stateNode`        | `any`                                       | 与此 Fiber 关联的本地状态实例。对于类组件，它是组件实例；对于 DOM 元素，它是 DOM 节点；对于函数组件，通常为 `null`。                                                              |
| **树结构关系** | `return`           | `Fiber \| null`                             | 指向处理完当前 Fiber 后需要返回的父 Fiber。这实际上是 Fiber 树中的父节点，但在处理过程中可能存在多个父级（例如双缓冲）。它在概念上类似于栈帧的返回地址。                               |
|                  | `child`            | `Fiber \| null`                             | 指向此 Fiber 的第一个子 Fiber。构成了单向链表的树结构。                                                                                                                          |
|                  | `sibling`          | `Fiber \| null`                             | 指向此 Fiber 的下一个兄弟 Fiber。构成了单向链表的树结构。                                                                                                                        |
|                  | `index`            | `number`                                    | 表示此 Fiber 在其父 Fiber 的子 Fiber 列表中的索引，用于优化列表的更新。                                                                                                          |
| **引用与清理** | `ref`              | `null \| ((handle: mixed) => void) \| RefObject` | 用于关联此 Fiber 对应的实例或 DOM 节点的引用。可以是函数、字符串（旧版）或 `RefObject`。                                                                                          |
|                  | `refCleanup`       | `null \| (() => void)`                      | 一个清理函数，用于在 Fiber 卸载时执行 `ref` 的清理逻辑。                                                                                                                         |
| **状态与属性** | `pendingProps`     | `any`                                       | 当前 Fiber 待处理的属性，即即将用于渲染的新属性。                                                                                                                                |
|                  | `memoizedProps`    | `any`                                       | 上一次成功渲染后使用的属性。用于比较 `pendingProps` 以判断是否需要更新。                                                                                                         |
|                  | `updateQueue`      | `mixed`                                     | 与此 Fiber 关联的状态更新和回调队列，例如 `setState` 或 `forceUpdate` 的调用。                                                                                                   |
|                  | `memoizedState`    | `any`                                       | 上一次成功渲染后使用的状态。对于函数组件，它存储 Hooks 的状态；对于类组件，它存储组件的 `state`。                                                                                |
|                  | `dependencies`     | `Dependencies \| null`                      | 此 Fiber 的依赖项（如 Context、事件）。如果存在，用于优化更新过程，避免不必要的重新渲染。                                                                                         |
| **模式与副作用** | `mode`             | `TypeOfMode`                                | 位字段，描述 Fiber 及其子树的属性，例如是否应该以异步模式（Concurrent Mode）渲染。通常从父级继承，但在创建时可以设置额外标志。                                                       |
|                  | `flags`            | `Flags`                                     | 位字段，表示此 Fiber 上存在的副作用（effects）。例如，`Placement`（插入）、`Update`（更新）、`Deletion`（删除）等。在协调阶段会被标记，并在提交阶段执行。                           |
|                  | `subtreeFlags`     | `Flags`                                     | 此 Fiber 及其所有后代中所有副作用标志的集合。用于快速判断子树是否存在副作用。                                                                                                     |
|                  | `deletions`        | `Array<Fiber> \| null`                      | 一个数组，存储了在此 Fiber 及其子树中需要删除的 Fiber 节点。                                                                                                                     |
|                  | `lanes`            | `Lanes`                                     | 表示此 Fiber 的更新优先级。Lanes 是一个位掩码，用于管理并发更新的优先级。                                                                                                         |
|                  | `childLanes`       | `Lanes`                                     | 表示此 Fiber 的子 Fiber 中最高优先级的更新。                                                                                                                                     |
| **双缓冲机制** | `alternate`        | `Fiber \| null`                             | 指向“替身”Fiber，即与当前 Fiber 对应的另一个 Fiber。在双缓冲机制中，React 会在后台构建一个新的 Fiber 树（`workInProgress` 树），当构建完成后，`alternate` 会指向旧树中对应的节点。 |
| **性能分析（Profiler）** | `actualDuration?`  | `number`                                    | 当前更新中，此 Fiber 及其后代渲染所花费的实际时间。仅在 `enableProfilerTimer` 标志启用时设置。                                                                                       |
|                  | `actualStartTime?` | `number`                                    | 如果 Fiber 当前处于“渲染”阶段，此字段标记工作开始的时间。仅在 `enableProfilerTimer` 标志启用时设置。                                                                                 |
|                  | `selfBaseDuration?` | `number`                                    | 此 Fiber 最近一次渲染的基准持续时间。当因 `memoization` 优化而跳过渲染时，此值不会更新。仅在 `enableProfilerTimer` 标志启用时设置。                                                |
|                  | `treeBaseDuration?` | `number`                                    | 此 Fiber 所有后代的基准时间总和。在“完成”阶段向上冒泡。仅在 `enableProfilerTimer` 标志启用时设置。                                                                               |
| **调试信息（仅 `__DEV__` 模式）** | `_debugInfo?`      | `ReactDebugInfo \| null`                    | 调试信息。                                                                                                                                                                       |
|                  | `_debugOwner?`     | `ReactComponentInfo \| Fiber \| null`       | 调试信息，指向拥有此 Fiber 的组件。                                                                                                                                              |
|                  | `_debugStack?`     | `string \| Error \| null`                   | 调试栈信息。                                                                                                                                                                     |
|                  | `_debugTask?`      | `ConsoleTask \| null`                       | 调试任务信息。                                                                                                                                                                   |
|                  | `_debugNeedsRemount?` | `boolean`                                   | 调试信息，指示是否需要重新挂载。                                                                                                                                                 |
|                  | `_debugHookTypes?` | `Array<HookType> \| null`                   | 调试信息，用于验证 Hooks 的顺序在不同渲染之间没有改变。                                                                                                                          |
